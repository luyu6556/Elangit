# Elangit｜首页重构开发计划

> 状态：方案已由用户确认，待开始实现
>
> 日期：2026-09-23
>
> 对应需求：`PRD.md` v0.7，H0-1～H0-7

## 1. 为什么改

原首页是素材库栅格，最擅长“找回一条已知素材”；但项目启动时，用户更需要的是连续判断“哪些素材适合这个项目”。项目翻阅牌堆已经形成清晰的核心体验，因此将它提升为首页，把“建立项目 → 快速选材”变成默认路径。

这不是删除素材库，而是调整优先级：

```text
原来：打开应用 → 素材库管理 → 再进入项目翻阅
改后：打开应用 → 全库卡片翻阅 → 选项目收藏
                              └→ 需要找回／管理时进入素材库
```

## 2. 已确认的产品规则

| 主题 | 已确认规则 |
|---|---|
| 首页队列 | 展示全库所有素材；已经收藏到一个或多个项目的素材仍显示。 |
| 左上入口 | “新建项目”；名称、构思、标签都可留空，创建后直接进入该项目翻阅。 |
| 右上入口 | “添加素材”；跳转既有 `add.html`，不改录入路径。 |
| 底部入口 | 页面底部居中“进入素材库”；进入完整的检索、筛选、编辑与管理页。 |
| 首页爱心 | 有当前项目则直接收藏；无当前项目先选“已有项目／新建项目”。 |
| 已有项目列表 | 默认仅展示进行中项目；可展开已归档项目，且必须标“已归档”。 |
| 卡片交互 | 继续复用现有牌堆：横向翻阅、点卡翻面读设计说明总结、背面进详情、右下爱心。 |
| 数据边界 | 同一素材可进入多个项目；页面不直连数据库，所有写入仍走 `store.js` 的 `guard()`。 |

## 3. 页面与路由方案

| 路径 | 改版后职责 | 来源／实现方向 |
|---|---|---|
| `app/index.html` | 应用首页：全库牌堆、左／右操作入口、底部素材库入口、项目选择弹层 | 保持根地址不变，使直接打开应用即到首页。 |
| `app/library.html` | 完整素材库：原首页的栅格、搜索、标签、抽屉、管理与全局收藏夹分享 | 从现有 `index.html` 整体迁移；不是重写或删减。 |
| `app/projects/deck.html?project=:id` | 某项目的定向翻阅 | 保持现有项目标签筛选、已收藏状态与项目上下文。 |
| `app/projects/index.html` | 项目清单与管理 | 保留现有能力，作为首页弹层以外的完整项目管理入口。 |
| `app/add.html` | 素材录入 | 不改。 |

导航迁移必须全量回查：原先指向 `index.html` 的“灵感库”链接要改为 `library.html`；品牌／根入口改指向新的 `index.html`。分享页的路径式 `/s/` 与 `/i/` 规则不动。

## 4. 实现顺序与影响文件

### A. 先保住素材库

1. 将当前首页完整迁入 `app/library.html`，包括所需脚本、相对路径与既有验证。
2. 更新全站内部“素材库”入口；逐页检查 `add.html`、`item.html`、`share.html`、`stats.html`、项目页。
3. 在真实浏览器验证检索、筛选、素材详情、编辑门禁与全局分享入口仍可用。

### B. 建立新首页牌堆

1. `app/index.html` 改为首页壳，加载全库轻量索引与按需缩略图；不得请求 `item_images.data_base64`。
2. 优先复用 `app/projects/projects.js`／`projects.css` 中已验证的牌堆几何和交互，不另写第二套拖拽、滚动、翻面判据。
3. 新增首页特有的 UI 状态：无项目、当前项目、选择项目弹层、展开归档项目、创建项目后跳转。
4. 所有收藏／建项目写入均调用现有项目数据层方法；不改 `items`、`item_images`、`settings` 表结构及既有分享令牌。

### C. 适配与验证

1. 桌面 1440px、平板 768px、手机 390px：左上／右上／底部入口均可用，中央卡始终是焦点，不出现横向溢出。
2. 真实浏览器覆盖：全库翻阅、创建无名称项目、选择已有进行中项目、展开并选择归档项目、重复收藏、取消收藏、进入素材库。
3. 回读数据库：测试项目与关联均按 ID 清理；不能只看界面“已恢复”。
4. 更新 `app/_verify_projects.html` 与既有首页验证台；不通过不发布。

## 5. 验收判据

| 场景 | 应得结果 |
|---|---|
| 无当前项目点爱心 | 出现选择／新建项目，不产生静默收藏。 |
| 选进行中项目后点爱心 | 当前素材仅与该项目建立关联；爱心转红。 |
| 展开归档项目 | 归档项目可见且标记清晰；选择后仍可收藏。 |
| 首页已收藏素材 | 仍留在全库翻阅队列；收藏状态以当前被选项目为准。 |
| 新建空名称项目 | 保存名为“未命名项目”，跳入该项目翻阅。 |
| 点击进入素材库 | 能进入保留原有能力的独立素材库页面。 |
| 原素材库关键能力 | 搜索、筛选、详情、编辑、全局分享、数据页无功能回归。 |

## 6. 本阶段明确不做

- 不发布线上，不执行 Git 命令。
- 不启动 P3-7 项目访客只读分享迁移。
- 不把项目信息写入 `items`，不增加埋点，不改现有分享令牌规则。
- 不以首页改版为理由压缩现有录入、检索和管理能力。

## 7. 实施前检查点

开始代码前先建立导航清单与现有 `index.html` 的资源依赖清单；此迁移最大的风险不是牌堆本身，而是“旧素材库还在、却有一部分入口仍错误指回新首页”。所有改动完成后必须以真实浏览器逐页点击回查，而不是只检查文件存在。
